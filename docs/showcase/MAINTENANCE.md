## 实现参考（不属于用户语义）

以下实现说明从旧记录移至此处，用于后续核查。它们不是用户要求或逐项认可，也不作为本次语义迁移重新验收产品的证据；使用时须对照当前源码。

当前可视化输入仍使用项目 goal/scope/constraints/acceptance、模块 purpose/inputs/outputs/behavior/boundaries/acceptance 等字段；这是模板输入结构，不是新的用户语义文件格式。语义文件的最终期望和当前阶段约定均映射到用户要求，实际做法另查产物。

模板的具体视觉编码由 Agent 选择：绿色表示有语义依据，橙色轮廓与“含未指定细节”标识已知未约定选择，灰色点线表示未核查，独立紫色表示方案待定；深蓝轮廓表示选中或键盘焦点，浅蓝链接表示关联跳转。上层引用框和空心边界圆点连接展开图的入口出口。颜色、角标和引用形状属于实现，不自动成为用户指定的样式。

模板采用 Python 入口 flow.py/build_report，提供顺序、分支汇合、等待回接和多模块交互布局。常用尺寸、换行、边界和路线由工具计算，通常建议四至七个主要节点；具体坐标、断点、控件尺寸和图例高度属于实现选择。

现有检查涵盖结构、节点/文字范围、绝对折线折点越界、正交连线穿过节点和关系文字覆盖节点或上下文框；字体范围是估算，复杂曲线和完整视觉效果仍需验看。统一入口从详情小图汇总状态，交互行为须在真实浏览器中按需核查。

当前生成器先写出 SVG/HTML，再执行检查；失败时可能留下或覆盖文件。输出保留政策尚未由用户约定，不能将这个实现描述为用户接受的保证。

当前判别实现区分可省附加机制、不能无替代省去的实现职责，以及异常保障或运行政策尚需取舍的项。移除范围要具体到可独立解释的机制，不因一层可省便把整个校验函数、格式或迁移记账一起删除。正常输入对照成功只证明该条件下的结果；失败场景、历史产物、调用契约与长期资源后果可能改变判断。证据不足时保留未知，不虚构节省量、必要性评分或阅读效率实测。判断采用源码依赖和适当的隔离对照，不固定必须使用哪些工具或测试流程；实验原型也不冒充已可发布的迁移方案。

完整性收尾的当前实现还采用来源独立的反查：有独立审查者且使用已获授权时，先让其从产物形成判断，再对照完整报告；没有这一条件时重新从产物作一次反查并说明局限。确认的遗漏和错误须合并修正到一致的最终报告，核查同类位置并复核剩余项，不能将已知漏项留在另一份报告中而宣布完成。独立参考也要服从真实源码证据。这里是本轮为实现用户完整披露目标选择的检查方法，不把多轮措辞加强或作者自信当成完整性的证明。

默认架构／流程图的连线由 Agent 选择为：深色箭头表示有依据的流程，蓝色箭头表示信息、调用或返回，灰色无向虚线表示约束与附注，红色虚线箭头表示相关异常；条件在连线上说明。职责泳道是可选布局，不固定列数或新增执行阶段。规则图中的判断结构只是对当前约定的图形解释，不代表已有自动状态机，也不规定工具执行顺序。

当前工具在节点、关系、交接线和分组上分别渲染状态，并向父模块汇总；未指定与未核查同时存在时保留两个标记，方案待定独立保留。详情小图的具体选择也应在所属项及父模块上提示；统一入口从小图节点和关系读取这些状态，底层直接组装时须传入相应状态。检查器核对详情小图与父级状态标记的保留、呈现结构，不能证明 Agent 已发现全部选择。

打印时展开全文、来源和图例，显示全部图层与小图说明；结束后恢复原有折叠状态，屏幕上的选择与隐藏分支保持原状。实际浏览器打印验证仍受本地 file URL 访问限制。

当前报告默认层级文案为用户约定／实际流程／关键步骤，单个视图可用 level_label 覆盖。links 的对象目标会自动获得返回引用项的链接；全文锚点只生成前向导航。链接与归属都属于报告输入，不是新的用户语义对象。

查看器选择节点时先显示替换内容，再收起旧分支，保留点击位置及图内视口；已可见时不主动滚动。普通展开只需露出下方内容的前 160px，页面和画布留 16px 边距，使用浏览器原生平滑滚动并尊重减少动态效果设置。精确链接保留缩放、将节点或关系文字移入画布；过大节点优先显示文字，初始深链接直接定位。以上是本次 Agent 选择的交互细节，用户要求是改善突兀跳转；本轮完成语法、纯滚动几何和生成检查，真实浏览器体验尚未验证。

文字对照由报告作者填写 comparisons：精确摘取两侧片段并给出判断与说明，模板不做文字 diff 或自动语义判断。绿色一致、红色偏离/未实现、橙色额外选择、灰色实现未核实，是本次 Agent 选定的显示方案；本项编号用于对照两侧，正文和来源保留。字段片段须唯一且不重叠；补充选择仅标实际侧，并保留外层未指定提示。

独立汇总页由现有 comparisons 生成，按偏离／遗漏、Agent 补充、未核实分组，省去已一致片段。具体词句直接展示，判断说明用原生 details 展开，双向链接到图中对应节点或关系；同名 summary.html 随报告写出并覆盖。仅本项状态参与兜底，父节点聚合的后代状态不重复入表；没有逐项标注的未指定选择与未核查范围仍保留，计数是摘要项而非唯一缺陷。分组、文件名、原生折叠与计数口径是 Agent 的呈现选择；不新增 JS 或第三方依赖。

报告页面的阅读方式入口放在标题下方，使用至少44px高、16px文字的有底色按钮；当前页深绿色，另一页浅绿色。条目详情入口紧邻条目标题，返回汇总入口使用同样的按钮式链接，至少40px高、14px文字。这些位置、尺寸与颜色是针对入口不显眼的反馈所作的 Agent 实现选择，仍使用原生链接。

## 当前状态表达实现

`summary_findings` 将约定未核查生成为内部 `unreviewed` 发现，与实现 `unverified` 分别呈现；作者填写的五种 comparisons 类型保持不变。正文或简图说明缺失独立生成未核实项，两类缺口可同时出现。

摘要组按本项 pending 显示“方案待定”，仅内部简图待定时显示“含待定方案”；简图节点／关系只把 pending 传给自身发现，不传给其他选择。只有待定状态、没有其他发现的项以内部 `pending` 类型保留；这两种新增分区只在有内容时显示。摘要数量仍是条目数，“其他待定方案”只统计没有其他类型的待定条目，不是全部待定数。状态标签使用原有灰／紫配色；完整原文、三字段和证据保留。

上述为本轮实现选择，不是新增用户约定；不引入实现前推演、确认字段或新的服务。临时输入通过真实模板生成检查状态路径；真实浏览器交互与视觉结果仍未验证。
