# 语义记录

## 目的

用明确、可直接修改的 Markdown 保存用户当前有效的语义，便于按范围检索和使用。

## 限制

遵循[项目共同限制](../SEMANTICS.md#限制)。正文保留完整条件、例外和约定含义；考虑常见工具的搜索、分段读取及局部修改能力，但不规定阅读工具、固定顺序或每次整节重读。

## 用户约定

### 记录结构与文件组织

**最终期望：** 让用户和 Agent 能区分完整目标、本阶段要做什么，以及各约定之间的关联。

**当前阶段约定：** 采用“目的、限制、用户约定”的组织方式。约定按用户关心的对象或能力分组，不要求固定经过“项目 → 模块 → 功能”的层级。每个约定主题保留“最终期望、当前阶段约定、本阶段完成条件、关联约定、关联文件”五个字段；主题可以是整体职责，也可以是具体行为，有明确细化关系时再展开。

用户明确的模块边界和功能关系仍属于约定；Agent 为阅读而作的分组标明整理身份。共同限制放在上层，主题特有限制就近写。格式说明须逐项解释各部分记录什么、各字段之间的区别及未约定时的写法，而不只提供标题。本阶段将已认可的组织方式用于正式 Skill，并同步安装版。

最终期望与当前阶段约定都来自用户；没有明确区分时保留未约定，不推演未来安排。完成条件已写在约定中时可引用，没说则标明未约定。实际实现、检查结果和 Agent 自行选择的实现细节放在检查或维护资料中。

关联文件支持多个文件或目录，区分用户明确指定的路径与 Agent 整理的索引；文件路径不证明实现。关联约定说明有依据的依赖、输入输出、细化或共同约束，不凭目录排布推断流程。

语义记录在 100 行以内使用单文件，超过 100 行时可以按主题拆分；不限制拆出文件的大小。入口保留共同含义和约定索引，索引不重复正文；说明中明确主文件和拆出文件的存放位置。文件边界用于存储，不自动成为模块边界。

**本阶段完成条件：** 结构明确，两类用户语义与真实实现分开；本次修改后须确认结果可视化仍可使用这些记录。

**关联约定：** 向[结果呈现与交付](audit.md#结果呈现与交付)提供用户原文和结构；向[要求与产物双向对照](audit.md#要求与产物双向对照)提供用户语义基线。

**关联文件：** [SKILL.md](../../../SKILL.md)：任务入口、语义检查边界和记录格式说明；[本项目入口](../SEMANTICS.md)：当前用户语义入口与主题索引；[view-content.md](../../../references/view-content.md)：报告内容、语义来源与记录到图的含义对应。

### 当前含义更新

**最终期望：** 记录直接表达当前共识，读者无需追溯设计演变。

**当前阶段约定：** 新约定替换已被取代的说法并同步受影响引用；保留未被取消的条件、例外和其他要求。保留变体写明适用条件，未解决的意图冲突保持明确，不能用“兼容”掩盖矛盾。

阶段推进时更新当前阶段约定；用户改变完整目标时更新最终期望，不追加开发历史。不把实际产物反写为用户要求，也不因实现存在或测试通过就视为用户接受。带日期的检查与示例保持其证据身份，不直接充当当前用户语义。

**本阶段完成条件：** 受影响含义形成一致的当前描述，保留本次未取消的要求；仍有冲突时说明未完成处。

**关联约定：** 接收[长期语义维护](activation.md#长期语义维护)识别的长期变更；保存[修复确认](audit.md#修复确认)中用户已接受的新约定。

**关联文件：** [SKILL.md](../../../SKILL.md)：任务入口、语义检查边界和记录格式说明；[本项目入口](../SEMANTICS.md)：当前用户语义入口与主题索引。

### 记录迁移

**最终期望：** 改变记录形式时不遗漏有效要求，也不改变原意。

**当前阶段约定：** 以当前有效用户含义为基准，核对所有条件、例外、阶段边界及未解决约定；按主题合并重复内容。实现资料与语义分开保留，不能把它们冒充用户认可，也不能因格式迁移而丢失资料。

停止旧生成器覆盖新正文；删除旧记录遵循实际授权，不把未安装或未知术语等同于无用。一次性核对和恢复备份不进入日常上下文；其他项目按实际请求处理。

**本阶段完成条件：** 全部有效要求保留且原意不变；本项目记录完成新格式转换并确认结果可视化仍可使用这些记录。

**关联约定：** 采用[记录结构与文件组织](#记录结构与文件组织)作为目标格式；按[说明与版本](packaging.md#说明与版本)将用户语义与安装资料分开保留。

**关联文件：** [本项目入口](../SEMANTICS.md)：当前用户语义入口与主题索引；[MAINTENANCE.md](../MAINTENANCE.md)：独立保存实现观察及维护资料；[SKILL.md](../../../SKILL.md)：任务入口、语义检查边界和记录格式说明。
